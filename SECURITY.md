# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose
**Report a vulnerability**. Include what you found, steps to reproduce, and the affected version.

You can expect an acknowledgement within a few days. Once a fix is released, the report can be
disclosed publicly with credit to you, if you wish.

## Scope

Hush stores data only on the device (liked songs and playlists) and talks only to YouTube hosts
through NewPipeExtractor. Reports about the app's handling of local data, its permissions, or its
network behaviour are in scope. Problems in YouTube itself or in upstream libraries should be reported
to those projects.
